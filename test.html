Function Notation

A function maps each input value to exactly one output value:

\[ \underbrace{y}_{\text{output}} = f(\underbrace{x}_{\text{input}}) \]

Evaluating Functions

For example, given the quadratic function \( f(x) = 2x^2 - x + 2 \):

\[ \begin{aligned} f(1) &= 2(1)^2 - (1) + 2 = 3 \\[6pt] f(0) &= 2(0)^2 - 0 + 2 = 2 \\[6pt] f(x-3) &= 2(x-3)^2 - (x-3) + 2 \end{aligned} \]

Graphs of Functions: Vertical Line Test

To determine if a graph represents a function, apply the vertical line test.

Passes Vertical Line Test

Each vertical line must intersect the graph at most once.

Fails Vertical Line Test

Crosses more than once → NOT a graph of a function.

Domain and Range

Domain: all acceptable input values

Acceptable:

\[ f(x) = \frac{3}{x - 2} \]
\[ f(1) = \frac{3}{1 - 2} = \frac{3}{-1} = -3 \](number out)

Unacceptable:

\[ f(x) = \frac{3}{x - 2} \]
\[ f(2) = \frac{3}{2 - 2} = \frac{3}{0} \]undefined — NOT a number

Common domain restrictions:

  • No division by zero
  • No even roots of negative number
  • etc.

Range: all possible output values

Domain and Range of a Radical Function

Example

Given function: \[ f(x) = \sqrt{x-5} \]

1. Finding the Domain

Domain rule: No even root of negative numbers.

So, set the radicand greater than or equal to zero: \[ x - 5 \ge 0 \]

Solving for \( x \): \[ x \ge 5 \quad \text{or} \quad [5, \infty) \]

Graphical representation on a real number line:

2. Finding the Range

  • The smallest possible value of \( x - 5 \) within the domain is \( 0 \) (when \( x = 5 \)).
  • So, the smallest value \( \sqrt{x - 5} \) can be is \( 0 \).
  • There is no maximum to \( x - 5 \) within the domain.
  • So there is no maximum to \( \sqrt{x - 5} \) either.

Therefore, the range of \( \sqrt{x - 5} \) is: \[ [0, \infty) \]

Composition of Functions

Concept: Using a function as the input of another function.

Given the following functions:

\[ f(x) = x^2 \]
\[ g(x) = \frac{1}{x-1} \]

1. Evaluating \( (f \circ g)(x) \)

\[ \begin{aligned} f(g(x)) &= (f \circ g)(x) \\[6pt] &= \underbrace{f\left(\frac{1}{x-1}\right)}_{\substack{\text{change all } x \\ \text{in } f(x) \text{ to } \frac{1}{x-1}}} = \left(\frac{1}{x-1}\right)^2 \end{aligned} \]

2. Evaluating \( (g \circ f)(x) \)

\[ \begin{aligned} g(f(x)) &= (g \circ f)(x) \\[6pt] &= \underbrace{g(x^2)}_{\substack{\text{change all } x \\ \text{in } g(x) \text{ to } x^2}} = \frac{1}{x^2 - 1} \end{aligned} \]

Symmetry of Functions

Even Functions & \(y\)-Axis Symmetry

If \( f(-x) = f(x) \), then \( f(x) \) is even and its graph has \(y\)-axis symmetry.

Example:

Let \( f(x) = x^2 \)

\[ f(-x) = (-x)^2 = x^2 = f(x) \]

Evaluating specific points confirms symmetry: \( f(-1) = 1 \) and \( f(1) = 1 \).

Odd Functions & Origin Symmetry

If \( f(-x) = -f(x) \), then \( f(x) \) is odd and its graph has origin symmetry.

Example:

Let \( f(x) = x^3 \)

\[ f(-x) = (-x)^3 = -x^3 = -(x^3) = -f(x) \]

Symmetric coordinate values: \( f(1) = 1 \) and \( f(-1) = -1 \).

Graph Transformations

1. Shifts (Translations)

\( y = f(x) + c \)
Shift vertically by \( c \)
\( y = f(x + b) \)
Shifts horizontally by \( b \):
  • If \( b > 0 \implies \) shift LEFT
  • If \( b < 0 \implies \) shift RIGHT

2. Stretches & Compressions

\( y = a f(x) \)
Vertical stretch or compression:
  • Stretch if \( a > 1 \)
  • Compression if \( 0 < a < 1 \)
\( y = f(bx) \)
Horizontal stretch/compress:
  • Stretch if \( 0 < b < 1 \)
  • Compress if \( b > 1 \)

3. Reflections

\( y = -f(x) \)
Vertical reflection (across \(x\)-axis)
\( y = f(-x) \)
Horizontal reflection (across \(y\)-axis)
